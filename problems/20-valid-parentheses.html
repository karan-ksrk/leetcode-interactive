20. Valid Parentheses

Easy String Stack Bracket Sequences View on LeetCode ↗
Problem description

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.
  3. Every close bracket has a corresponding open bracket of the same type.
Ex 1: s = "()" → true
Ex 2: s = "()[]{}" → true
Ex 3: s = "(]" → false
Ex 4: s = "([])" → true
Ex 5: s = "([)]" → false

Constraints: 1 <= s.length <= 104; s consists of parentheses only '()[]{}'.

Python Solution


      

        
Idea: Push every opening bracket. On a closing bracket, the most recent unclosed opener (stack top) must be its partner — otherwise the string is invalid. At the end, the stack must be empty.

        
Time: O(n) — each character pushed/popped at most once.
Space: O(n) — stack can hold up to n openers.
