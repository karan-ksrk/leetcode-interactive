LeetCode #20 Easy Stack String

Valid Parentheses

“Openers wait on the stack; every closer must match the top.”

You get a string s made only of ( ) [ ] { }. It is valid when every opening bracket is closed by the same type, brackets close in the right order (the most recent opener closes first), and every closer has a matching opener. Return true or false.

MOVE 1 · PUSH

Opener? Push it

ch in "([{" → stack.append(ch)

An opener can't be judged yet. Park it on the stack until its partner shows up.

MOVE 2 · PEEK

Closer? Check the top

stack[-1] == pairs[ch] ?

Only the most recent unclosed opener is allowed to close now. Compare it with this closer.

MOVE 3 · POP

Match → pop

stack.pop()

The pair is done. Removing it shows the next opener that still needs closing.

MOVE 4 · FAIL FAST

Empty or wrong → false

not stack or top ≠ pair → return False

A closer with nothing to close, or the wrong bracket type, fails right away.

MOVE 5 · FINAL

Stack empty at end?

return not stack

Any openers still on the stack were never closed, so the string is invalid.

Why it's fast

Key insight: brackets nest, so the last opener must close first (last in, first out). A stack follows that rule directly. Each character gets pushed at most once and popped at most once, so a single pass is enough.

  • Time: O(n). One pass, O(1) work per character.
  • Space: O(n). In the worst case (e.g. "((((") every character is on the stack.
  • Early exit: a mismatch stops the scan immediately. Odd-length strings can't be valid either.
