Two Sum: Scan and Store

Find two numbers that add to a target in one pass. Store each number in a hash map as you scan, so when you find a complement, you're done.

Algorithm Moves

Scan
Read one number
Check if its complement exists in the map
Found
Match found
Both numbers add to target
Store
Add to map
Remember this number for future matches

Why It's Fast

            

                
Key Insight

                
One hash map lookup per element. No nested loops, no searching.

            

            

                
Complexity

                
Time: O(n) — one pass through the array
Space: O(n) — hash map stores up to n elements

            

            

                
vs Brute Force

                
Brute force: O(n²) nested loops checking every pair. This: O(n) with one pass.
