# LeetCode Problem HTML Generator

Generate a SINGLE standalone HTML file that visualizes how the algorithm works.

Include:
1. Problem title and description at top
2. Animated visualization of the algorithm in action
3. Step-through controls: Play, Next, Back, Restart buttons
4. Show the current state (variables, data structures) as you step through
5. Display the Python solution code with current line highlighted
6. Support keyboard: Space=play, arrows=step, R=restart

Technical requirements:
- Embed everything in ONE HTML file (no external files)
- Use vanilla JS and CSS (no libraries)
- Responsive design
- Dark mode support via prefers-color-scheme
- Accessibility: aria-live for narration, keyboard navigation

Output just the HTML now. Do not explain. Do not add prefix/suffix text.
